CheckCTS — Kiểm tra chữ ký số

Kiểm tra file PDF đã ký & chứng thư trong USB token đang cắm

Hướng dẫn sử dụng

Cách 1 — Ký tài liệu bằng chữ ký số rồi đẩy lên web để kiểm tra

  1. Mở tài liệu cần ký (file PDF) bằng phần mềm ký số bạn đang dùng (VGCA SignService, Foxit, iText, phần mềm CKS của đơn vị…).
  2. Cắm USB token, chọn chứng thư của bạn và ký lên file PDF, lưu lại file đã ký.
  3. Tại mục “1. Kiểm tra file PDF đã ký” bên dưới, kéo–thả (hoặc bấm chọn) file PDF đã ký vào.
  4. Web hiển thị: người/tổ chức ký, đơn vị (OU), cơ quan chủ quản (O), số serial, hạn hiệu lực, tính toàn vẹn, dấu thời gian (TSA).
  5. Bấm “Xuất Excel / PDF” ở mục 3 để lưu biên bản kiểm tra.

Cách 2 — Kiểm tra bằng công cụ tải về (đọc trực tiếp USB token)

  1. Tại mục “2. Đọc USB token”, bấm “Tải CheckCTS-Agent.exe” (đọc token ngay trên web) hoặc “Bản offline đầy đủ (.exe)”.
  2. Chạy file vừa tải (không cần cài đặt):
    • Agent: để cửa sổ “Đang chạy” mở, quay lại web bấm “Dò & đọc token”.
    • Bản offline: mở giao diện, chọn PDF hoặc bấm “Đọc token”, xem kết quả và “Lưu ra .txt”.
  3. Xem thông tin các chứng thư trong token (tên, đơn vị, cơ quan chủ quản, hạn).
Lưu ý về đơn vị hành chính (từ 01/7/2025): Cả nước áp dụng chính quyền 2 cấp (tỉnh – xã), bỏ cấp Huyện; tỉnh Hà Giang đã sáp nhập vào tỉnh Tuyên Quang. Vì vậy nếu chứng thư còn ghi “tỉnh Hà Giang” hoặc có cấp “Huyện” thì thông tin đơn vị đó không còn phù hợp — công cụ sẽ tự cảnh báo ở từng chứng thư.
